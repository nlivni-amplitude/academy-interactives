The four frustration signals
Rage click
Rapid repeated clicks on the same element. The user expected a response that didn't come.
Dead click
Click on an element that isn't interactive. Something that looks like a button or link but doesn't respond.
Error click
Click that triggered a JavaScript error in the session. The interaction caused something to break.
Form abandonment
User started filling a form and left without submitting. Intent was there; completion wasn't.
