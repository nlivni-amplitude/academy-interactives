Explained in non-technical terms
Each eligible shopper has a fixed lottery number that never changes. Raising the dial only ever lets more of them in, nobody already passing gets dropped. Lowering it re-runs the same numbers against a stricter cut, so whoever now sits above the line loses access. It's not random churn, it's the same deterministic number being measured against a new threshold.

This is why you can't lower a rollout to remove one specific person, the dial doesn't target individuals. To guarantee someone never sees a feature, an override set to fail or an explicit exclusion rule is the tool, not the percentage.
