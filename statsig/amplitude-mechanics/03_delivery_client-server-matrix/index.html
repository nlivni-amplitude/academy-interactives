Two questions, kept apart. What you're testing picks client or server: if a shopper could screenshot the difference it's client, if it's invisible logic like pricing or ranking it's server. Brains or speed picks remote or local: cohorts, geo, and sticky bucketing need remote, while sub-millisecond and high request rates need local.
