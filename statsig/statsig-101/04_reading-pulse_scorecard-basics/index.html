The scorecard updates every day. Not every number on it is ready to be read the same way. Tapping into each one below shows the check to run first.

Participation isn't the same as assignment ›

Fewer people in a metric than you assigned to the experiment

Assignment counts everyone the experiment touched. Participation counts only the people who actually did the thing the metric measures. If half your assigned users never reached the checkout page, the checkout metric was only ever going to have half the group in it, no bug required.

Yesterday's number is still cooking ›

The last day or two on the chart looks worse than the rest

Conversions that happen a few days after exposure haven't all landed yet for anyone exposed in the last day or two. That trailing dip isn't the trend, it's incomplete data waiting on its attribution window to close. Read the bake window in the metric's setup before reacting to a recent dip.

A confidence interval touching zero isn't a result yet ›

The point estimate says +3%, but is that real

The point estimate is one number, the confidence interval is the honest range around it. If that range still spans zero, a true effect of nothing at all is still consistent with what you've measured. The point estimate moving doesn't mean the interval has closed around it.

All three come back to the same habit: check what a number is actually built from before deciding what it means.
