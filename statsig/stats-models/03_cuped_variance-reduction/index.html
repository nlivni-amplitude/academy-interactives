Explained in non-technical terms
Kids race to test new shoes, but some kids are just naturally fast, so the shoe effect is buried. CUPED checks how fast each kid ran last week, then asks whether they beat their own usual pace. Once everyone is measured against themselves, the shoe's real effect stands out fast. It uses each user's pre-experiment behavior as the baseline, so the part of the result that was always going to happen gets subtracted out.

At AmpliStore the regulars' spending gets netted against their own 30-day history, the interval tightens by roughly 40%, and a test that needed four weeks reads out in about two and a half. Both platforms run it: Statsig per metric, extended as CURE on Warehouse Native, and Amplitude as an advanced setting framed around correcting pre-exposure bias.
